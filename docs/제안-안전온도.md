# 제안: 나의 안전 온도

2026-11-03 · 시험 기능 · `feat/app-safety-temperature` 브랜치에만 있음

앱을 꾸준히 쓰며 남긴 기록으로 올라가는 개인 지표입니다. 시연 기준 버전(#19, #20)에는 들어 있지 않습니다. 팀 합의 전까지 이 브랜치에서만 관리합니다.

## 왜 넣는가

- 작업자가 앱을 계속 켤 이유를 늘립니다. 기획서의 핵심 가치 1번(`작업자가 앱을 켤 이유`)과 연결됩니다.
- 출근, 작업 전 확인, 서로 확인이 쌓이는 모습을 작업자가 직접 봅니다.

## 기준 문서와 충돌하는 점

| 문서 | 내용 | 이 기능 |
| --- | --- | --- |
| [wireframe.md 1장](wireframe.md#넣지-않는-것) | 점수, 순위, 게임 같은 보상은 넣지 않음. 안전을 점수로 표시하지 않음 | 숫자를 보여 줌. 순위와 비교는 없음 |
| [기획서 3장](기획서.md#범위-밖) | 채용 점수·순위는 범위 밖 | 본인만 보고 서버로 보내지 않음 |

합치기 전에 헌장과 와이어프레임을 고칠지, 이 기능을 뺄지 팀이 정해야 합니다.

## 위험과 대응

| 위험 | 대응 |
| --- | --- |
| 반장·사업주가 일용직을 고르는 데 씀 | 폰 안에서만 계산하고 서버와 관리자 화면에 보내지 않음 |
| 온도 때문에 무조건 `확인`을 누름 | `모름`, `개선 필요`도 `확인`과 똑같이 오름 |
| 사고를 숨김 | 사고, 호출, 무응답, 결근으로 내려가지 않음 |
| 같은 기록을 반복 입력 | 항목별 하루 횟수 제한과 하루 최대 +0.6°C |
| 다른 사람과 비교 | 순위, 평균, 다른 사람 온도를 보여 주지 않음 |

## 계산

처음에는 모두 36.5°C에서 시작합니다. 기록을 남긴 날만 오르고 내려가지 않습니다.

| 기록 | 오르는 양 | 하루 최대 |
| --- | --- | --- |
| 출근 | +0.1 | 1번 |
| 퇴근 기록 | +0.1 | 1번 |
| 작업 전 3가지 확인 | +0.1 | 1번 |
| 동료와 서로 확인 | +0.2 | 1번 |
| 작업 중 확인 응답 | +0.1 | 2번 |
| 위험 신고·조치·재확인 | +0.1 | 2번 |
| 동료 돕기(호출 수락·도착) | +0.3 | 1번 |

하루 최대 +0.8°C입니다. 동료를 챙긴 기록(서로 확인, 동료 돕기)이 가장 많이 오릅니다.

## 이름표

| 온도 | 이름표 |
| --- | --- |
| 36.5°C~ | 함께 시작 |
| 39°C~ | 든든한 동료 |
| 42°C~ | 믿음 가는 동료 |

출근, 퇴근, 작업 전 확인, 서로 확인을 매일 하면 하루 +0.5°C라 5일 근무에 `든든한 동료`, 11일 근무에 `믿음 가는 동료`가 됩니다. 며칠 만에 누구나 받는 이름표가 되지 않도록 정했습니다.

## 공개 범위

지금은 온도와 이름표 모두 본인만 봅니다. 동료에게 보여 주는 기능은 커뮤니티를 만들 때 아래 조건으로 다시 정합니다.

- 본인이 `동료에게 보이기`를 직접 켰을 때만 공개
- 반장·관리자 화면과 보고서에는 넣지 않음
- 숫자 없이 이름표만 보여 주는 선택지 제공
- 혼자 일하는 날이 많으면 덜 오르므로 기회 차이를 안내

## 화면

- `내 정보` 프로필 카드: 온도, 막대, 이름표, 이번 달 오른 양
- `나의 안전 온도` 상세: 이름표와 다음 이름표까지 남은 온도, 동료를 챙긴 기록, 이번 달 기록한 날 달력, 항목별 횟수, 오르는 규칙, `평가에 쓰지 않아요` 안내
- 퇴근 후 `오늘` 탭: 오늘 오른 온도

## 남은 일

- 폰에서 화면 확인
- 연결 모드에서는 앱이 불러온 기록으로만 계산하므로, 불러오지 않은 지난 달 기록은 빠질 수 있음
- 기기를 바꾸면 체험 기록 온도는 처음부터 다시 시작함
