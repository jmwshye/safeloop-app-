## 앱 진행 상황

앱 화면을 와이어프레임 기준으로 다시 만들었습니다. 1-5 카메라 화면은 기존 앱 카메라를 그대로 씁니다. 아래 실기기 확인은 갤럭시 S21+(Android 14, 글자 크기 1.5배)에서 한 결과입니다.

| 기능 | 체험 모드(서버 없음) | 실기기 확인 |
| --- | --- | --- |
| 출퇴근, 예상 일당, 월별 기록 | 동작 | 확인 |
| 내보내기 | 동작 | CSV, 월간 집계 PDF, 사고 보고서 PDF 확인. 근로 기록 PDF 미확인 |
| 작업 전 3가지, 동료 사진, 교차 인증 | 동작 | 확인. 불일치 화면 미확인 |
| 고위험 작업, 체크인 | 동작 | 확인. 13:00, 15:30 자동 체크인과 5분 무응답 처리 미확인 |
| 움직임 감시, 15초 확인, 동료 호출 화면 | 동작. 다른 폰으로 전달은 안 됨 | 확인. 실제 충격 감지 1회 확인, 오탐 측정 전 |
| 경보, 음성 안내, 구조 신호 | 동작 | 확인. 잠금 화면 표시 미확인 |
| 말로 응답(`괜찮아`, `도와줘`), 말로 위험 신고 | 동작. 폰의 음성 인식 서비스 필요 | 확인. 시끄러운 현장 미확인 |
| 도움 요청 때 상황 녹화(소리 없음, 30초) | 동작 | 확인 |
| 사진 얼굴 자동 가리기 | 동작. 확인 화면은 원본, 기록은 가린 사진. 원본은 올린 사람만 열람 | 시험 사진으로 확인. 원본 분리 저장은 폰 미확인 |
| 위험 신고, 익명, 조치, 재확인 | 동작. 재확인은 체험 예시 | 확인 |
| 타임라인, 사고 경위 보고서, 월간 집계 | 동작 | 확인 |
| 기록 변경 탐지, 낙하 높이 추정 | 동작 | 화면 캡처와 단위 테스트만 확인 |
| 큰 글자(1.5배) 줄바꿈: 타임라인 시각, 위험 현황 숫자, 홈 확인 카드 | 동작 | 화면 캡처만 확인. 폰 미확인 |
| 로그인, 현장 참여, 폰 2대 호출, 푸시 | 서버 필요 | 미확인 |

앱 코드 주석에 화면 번호(예: `3-1`)를 적어 와이어프레임과 연결합니다.

**로그인은 앱과 서버 코드가 이미 있습니다.** 실제 폰에서 쓰려면 서버가 켜져 있고 앱이 그 주소를 알아야 합니다. 기본 주소는 에뮬레이터 전용(`10.0.2.2:3000`)이라 폰에서는 연결되지 않습니다. 개발 빌드는 가입 화면에서 연결 실패 뒤 `https` 서버 주소를 입력할 수 있어 APK를 다시 만들지 않아도 됩니다. 서버 없이 시연할 때는 `체험 먼저 해보기`를 쓰거나 `체험 모드로 계속`을 누릅니다. 체험 모드 기록은 그 폰에만 저장되고 다른 폰으로 호출이 가지 않습니다.

**시연에 필요한 것:** 서버 주소(`https`), FCM 서버 인증 설정, 시연용 계정 2개, 현장 코드, 안전 동료 배정, Android 폰 2대.
