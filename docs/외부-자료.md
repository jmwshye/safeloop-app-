# 외부 자료 출처

앱에서 쓰는 외부 기술과 자료입니다. 새로 추가하면 여기에 한 줄 적습니다.

| 종류 | 쓰는 곳 | 출처 | 라이선스 | 처리 위치 |
| --- | --- | --- | --- | --- |
| 얼굴 찾기 라이브러리 | 사진 속 얼굴 자동 가리기 | [MediaPipe Tasks Vision](https://github.com/google-ai-edge/mediapipe) | Apache 2.0 | 폰 안 |
| 얼굴 찾기 모델 | `app/src/main/assets/blaze_face_short_range.tflite` | [MediaPipe BlazeFace](https://ai.google.dev/edge/mediapipe/solutions/vision/face_detector) | Apache 2.0 | 폰 안 |
| 음성 안내 | 긴급 안내 읽어 주기 | Android `TextToSpeech` | 폰 기본 기능 | 폰 안 |
| 말소리 인식 | 도움 요청, 위험 신고 | Android `SpeechRecognizer` | 폰 기본 기능 | 폰에 있는 인식 서비스. 인터넷을 쓸 수 있음 |
| 화면 캡처 시험 | 개발 시험 전용, 앱에 포함 안 됨 | [Robolectric](https://github.com/robolectric/robolectric), [Roborazzi](https://github.com/takahirom/roborazzi) | MIT, Apache 2.0 | 개발 PC, CI |
| 글꼴 | 서버 PDF, 화면 캡처 시험 | `backend/assets/fonts/NotoSansKR.ttf` | SIL OFL 1.1 | |

말소리는 저장하지 않고 글자로 바꾼 결과만 사용합니다. 사진 속 얼굴을 찾은 결과는 폰 밖으로 보내지 않습니다.
